Backup & restore

Everything lives only in this tablet's browser. Save a backup file regularly so you don't lose your roster and pass history if browser data ever gets cleared.

App name

Shown in the banner. Change this if another school is using this app, or hide it if your banner image already has your school name on it.

Banner image

Upload a wide photo or graphic (like a Google Classroom or Facebook cover photo) to use as the entire top banner. It will stretch to fill the strip, so a wide image works best.

Theme color

Changes the color used for buttons, the banner (when no image is set), and other accents throughout the app.

Pass timer threshold

Timer turns red after this many minutes.

Student PIN

Require each student to enter their own PIN before checking in or out. Turn this on if kids start tapping each other's names.

Staff PIN

Required to open the Teacher Dashboard and Settings from the kiosk.

Class periods

These show up as the first screen on the kiosk. Rename, retime, or add periods to match your school's schedule.

Roster

Each student's 2-digit PIN protects them from someone else tapping their name on the kiosk. Assign each student to a class period so they show up on the right kiosk screen.

Restricted pairs

These students can't be out at the same time.
